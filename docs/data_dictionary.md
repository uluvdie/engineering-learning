# 机电设备台账字段字典

## 1. 文件级约定

- 文件格式：`.xlsx`
- 默认工作表名称：`DeviceLedger`
- 第一行为表头，第二行开始为设备数据
- 本样例仅使用虚构设备、虚构站点和私有网段地址
- 不允许包含真实账号、口令、联系人和内部生产拓扑

## 2. 字段定义

| 字段 | 含义 | 数据类型 | 必填 | 示例 | 校验规则 |
|---|---|---|---|---|---|
| 设备编号 | 唯一识别一台设备的业务编号 | 文本 | 是 | GZ-CAM-001 | 不能为空；全表唯一；比较前去除首尾空格 |
| 设备名称 | 设备的中文名称 | 文本 | 是 | 入口车道摄像机01 | 不能为空 |
| 设备类型 | 设备所属类别 | 文本 | 是 | 摄像机 | 不能为空；后续必须属于允许类型 |
| 所属站点 | 设备所在测试站点 | 文本 | 是 | 测试收费站A | 不能为空 |
| IP地址 | 设备管理或通信地址 | 文本 | 是 | 192.168.10.21 | 不能为空；合法IPv4；全表唯一 |
| 安装位置 | 设备的具体安装位置 | 文本 | 是 | 入口1车道 | 不能为空 |
| 厂家 | 设备生产厂家 | 文本 | 否 | 示例厂家A | 允许为空；本月不校验唯一性 |
| 维护日期 | 最近一次维护日期 | 日期或文本 | 否 | 2026-07-15 | 允许为空；必须为有效日期；最终输出YYYY-MM-DD |

## 3. 规范化规则

1. 文本字段在比较前去除首尾空格；
2. 空单元格、空字符串和仅含空格的字符串均视为空值；
3. 设备编号和IP地址按规范化后的值检查唯一性；
4. IP地址本月只支持IPv4；
5. 维护日期允许Excel日期对象或可解析字符串；
6. 所有问题必须保留原始Excel行号和原始值。

## 4. 本阶段暂不处理

- 不检查厂家名称是否统一；
- 不检查站点名称是否属于真实组织机构；
- 不连接真实资产系统；
- 不处理IPv6；
- 不对设备类型建立完整行业分类。
